# Grab

Простий завантажувач відео та музики з YouTube та багатьох інших сайтів.
Графічний інтерфейс на Rust (egui), під капотом — [yt-dlp](https://github.com/yt-dlp/yt-dlp) та ffmpeg.

## Можливості
- Черга завантажень: прогрес, швидкість, ETA, розмір, загальна швидкість
- Відео до 2160p (mp4) або аудіо: mp3, m4a, opus, flac, wav
- Плейлисти, субтитри, обкладинка у файл, ліміт швидкості
- Теми (темна, світла, «Опівніч», «Ліс») та акцентний колір
- yt-dlp і ffmpeg завантажуються автоматично при першому запуску (Windows/Linux x64)
- Кнопка «Вставити з буфера» — працює на будь-якій розкладці


## Відмова від відповідальності
Користуйся лише для контенту, який маєш право завантажувати. Умови сервісів
(зокрема YouTube) можуть забороняти завантаження — відповідальність на користувачі.
