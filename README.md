# Grab

Простий завантажувач відео та музики з YouTube та багатьох інших сайтів.
Графічний інтерфейс на Rust (egui), під капотом — [yt-dlp](https://github.com/yt-dlp/yt-dlp) та ffmpeg.

## Можливості
- Черга завантажень: прогрес, швидкість, ETA, розмір, загальна швидкість
- Відео до 2160p (mp4) або аудіо: mp3, m4a, opus, flac, wav
- Плейлисти, субтитри, обкладинка у файл, ліміт швидкості
- Теми (темна, світла, «Опівніч», «Ліс») та акцентний колір
- yt-dlp і ffmpeg завантажуються автоматично при першому запуску (Windows/Linux x64)
- Вбудовані шрифти Inter (текст) та JetBrains Mono (швидкість, ETA, розмір) з кирилицею
- Кнопка «Вставити з буфера» — працює на будь-якій розкладці

## Нове
- Пауза / продовження, повтор невдалих одним кліком, фільтри черги (Усі / Активні / Завершені / Невдалі)
- Черга зберігається між запусками й дозавантажується після перезапуску
- Перетягування `.txt` / `.url` з посиланнями у вікно; дублікати посилань ігноруються
- Автоматичні папки «Відео» / «Музика» (+ за каналом), шаблони назв файлів
- Відкриття готового файлу, сповіщення після завершення черги
- Автопідхоплення посилань із буфера (в налаштуваннях)
- Гарячі клавіші: Ctrl+Enter, Ctrl+Shift+V, Ctrl+1/2/3

## Автооновлення
При запуску програма перевіряє останній реліз на GitHub і, якщо є новіша версія, сама завантажує її та перезапускається.
Теги релізів мають бути у форматі `vX.Y.Z` (наприклад `v1.2.0`) — версія в `Cargo.toml` підставляється з тегу автоматично.

## Відмова від відповідальності
Користуйся лише для контенту, який маєш право завантажувати. Умови сервісів
(зокрема YouTube) можуть забороняти завантаження — відповідальність на користувачі.



Інсталятор встановлює Grab у профіль поточного користувача (`%LOCALAPPDATA%\\Programs\\Grab`), тому для встановлення не потрібні права адміністратора. Після встановлення програму можна видалити через «Програми та компоненти» / «Встановлені програми».

Для локальної збірки інсталятора: спочатку виконай `cargo build --release`, встанови Inno Setup 6, а потім запусти `ISCC.exe installer\\Grab.iss` з кореня репозиторію.
